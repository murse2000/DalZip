## 사용자 동의 기반 자동 업데이트

- 실행 시 및 6시간마다 새 버전을 확인하고 알림을 표시합니다.
- 설정에서도 업데이트를 확인할 수 있습니다.
- ‘업데이트 설치’에 동의한 경우에만 다운로드·서명 검증·설치·재시작을 진행합니다.
- ‘나중에’를 선택하면 다운로드하지 않습니다. 압축·해제 작업 중에는 설치하지 않습니다.
- Windows x64와 Apple Silicon에 맞는 업데이트 파일을 사용합니다. macOS 업데이트에도 Finder 확장이 포함됩니다.

v0.1.0 사용자는 이번 버전을 한 번 직접 설치해야 합니다. 이후 버전부터 앱 안에서 동의하고 업데이트할 수 있습니다.

업데이트 파일의 암호학적 서명 검증을 적용했습니다. 이는 OS 배포용 코드 서명과 별개입니다. macOS Developer ID 공증과 Windows 코드 서명은 아직 적용되지 않았습니다.
